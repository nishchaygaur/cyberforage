# Cyberforage 3D — Explore. Build. Defend.

> A complete, high-fidelity 3D interactive web ecosystem for **[Cyberforage](https://cyberforage.space/)** — exploring cybersecurity, security research, intelligent automation, and defensive engineering.

---

## 🌟 Key Features

### 1. 🌐 Interactive 3D Cyber Defense Globe (Three.js)
- **Holographic Continents Matrix**: Thousands of pulsating cyber particles arranged along spherical contours.
- **Orbital Satellite Nodes**:
  - `SECURITY`: SOC & Detection engineering.
  - `AI`: Autonomous triage models & agentic containment.
  - `RESEARCH`: Binary reverse engineering & DFIR testbeds.
  - `AUTOMATION`: Orchestration pipelines & telemetry listeners.
- **3D Red-Team Attack Missile Trajectories**: Live quadratic Bezier packet arcs shooting into defense nodes, triggering defensive shields and telemetry warnings.
- **Interactive Perspective Switcher**:
  - 🌐 **Defense Globe**: Orbiting Earth with global sensor relays.
  - 🖥️ **Lab Blades Rack**: 3D modular server blades representing each cyber lab.
  - 🕸️ **Security Mesh**: 3D triangular telemetry loop (Defense Core ⟷ Threat Stream ⟷ AI Automation).
  - 🧭 **Free Orbit**: Unconstrained 360-degree rotation and zoom.

### 2. ⚡ Tactical Cyber Terminal / CLI Console
- Floating draggable/expandable hacker terminal toggleable via **`~`** (backquote) or **`Ctrl+K`**.
- Integrated command parser:
  - `help` — Tactical command index.
  - `status` — Real-time telemetry, uptime, and sensor health.
  - `scan` — Animated endpoint vulnerability and socket triage.
  - `simulate` — Triggers 3D hostile missile trajectory into defense shields.
  - `projects` — Direct links to live platforms (*Audit Platform*, *PDF Malware Analyzer*, etc.).
  - `labs` — Queries all 5 lab environments with difficulty metrics.
  - `mode <globe|server|mesh|free>` — Changes 3D camera viewpoint.
  - `audio [on|off]` — Toggles Web Audio API sound effects.
  - `intel` — Live threat intelligence bulletins.
  - `whoami` — Operator credentials and authorization clearance.
  - `contact` — Secure transmission coordinates.

### 3. 🧪 Cyberforage Labs & Detonation Sandbox
- **5 Hands-on Lab Testbeds**:
  1. **CyberForge**: Controlled attack simulation & telemetry evaluation.
  2. **Detection Engineering**: SIEM correlation, Sigma & YARA-L pipelines.
  3. **DFIR**: Digital forensics, memory analysis & timeline reconstruction.
  4. **Malware Analysis**: Static/dynamic PDF & binary reverse engineering.
  5. **Network Security**: Packet inspection, DNS tunneling detection & Zeek rules.
- **Interactive Detonation Runner**: Step through isolated container creation, adversary detonation, live Sysmon/Zeek telemetry ingestion, rule correlation, and automated containment.

### 4. 🛡️ Featured Projects Showcase
- **Audit Platform** (`https://audit.cyberforage.space/`, Docs: `https://audit.cyberforage.space/docs`): Web-based GRC & compliance management with automated evidence hashing.
- **CyberForge**: Advanced adversary emulation and detection evaluation platform.
- **PDF Malware Analyzer** (`https://pdfanalyzer.cyberforage.space/`): Heuristic and YARA-based malicious PDF structural parser.
- **SentinelX**: AI-powered autonomous SOC and telemetry enrichment platform.

### 5. 🔬 Research & Threat Intelligence Matrix
- **6 Core Disciplines**: Cyber Defense, Threat Intelligence, Security Research, AI × Security, Cloud & Enterprise, Automation.
- **In-Depth Article Reader**:
  - *Understanding Modern Phishing Tactics (AiTM proxies & FIDO2 defenses)*
  - *The Rise of Stealer Malware (Lumma, RedLine & NT syscall evasion)*
  - *LLMs in Cybersecurity Operations (Autonomous SOC triage & RAG)*

### 6. 🛠️ Modern Tech Stack & Search
- Quick search & category filtering for 10 core technologies: **Python, Linux, PostgreSQL, Docker, GitHub, YARA, MITRE ATT&CK, NIST CSF, Cloud Zero Trust, and AI/ML**.

### 7. 🔊 Native Web Audio Cyber Synthesizer

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation & Development
```bash
# Clone or navigate to the directory
cd Cyberforage3d

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
